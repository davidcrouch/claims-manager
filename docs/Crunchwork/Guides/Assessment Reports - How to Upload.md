NOTE: THIS GUIDE EXPLAINS HOW TO UPLOAD AN ASSESSMENT REPORT IN THE CRUNCHWORK CRM. THIS APPLICATION IS AN ALTERNATIVE TO USING CRUNCHWORK CRM AND SHOULD SUPPORT THE SAME FEATURES AND FUNCTIONALITY.


You can submit Assessment Reports to the Insurer by uploading the report document within the Attachments section of your Builder Assessment Job.

💡To learn the basics of uploading Attachments, how to create Attachment Folders and Insurer visibility, see Uploading Attachments. 

When uploading Assessment Reports, it’s important to title them appropriately and select the Document Type as ‘Assessment Report’ before clicking ‘Upload’. This will ensure the Insurer is alerted that you’ve submitted your Assessment Report for their review.


ℹ️ Files should always be uploaded to the Attachments section at the Job level and never at the Project level.
