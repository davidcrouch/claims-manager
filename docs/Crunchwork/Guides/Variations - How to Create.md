NOTE: THIS GUIDE EXPLAINS HOW TO CREATE A VARIATION IN THE CRUNCHWORK CRM. THIS APPLICATION IS AN ALTERNATIVE TO USING CRUNCHWORK CRM AND SHOULD SUPPORT THE SAME FEATURES AND FUNCTIONALITY.

Variations are used when changes are required after a quote has already been approved.

💡 Not sure what a quote is? See Quotes.

 

When to Create a Variation
A variation should be created when:

A quote has already been approved AND

Additional work is required OR

Costs need to be increased or decreased OR

Approved items are no longer required

 

This most commonly occurs on:

Builder Make Safe jobs

Builder Works jobs

Examples include:

Additional damage was discovered after the works began

Changes to the scope of repairs

Adjustments to previously approved costings

Removal of items that are no longer required

 

Once approved, variation items will be added to the existing Purchase Order for the job.

💡 Not sure how Purchase Orders work? See How to View a Received Purchase Order.

 

Variation Types
Crunchwork includes two variation quote types.

 


Quote type options

 

Variation
This is the standard variation type used when:

Adding additional items

Adjusting pricing

Removing items

Updating quantities

 

A Reason for Variation field must also be selected when creating the variation.

 


Reason for Variation field on a Quote

 

One option is Negative Variation, which should be used when:

Items are removed from the scope

Costs decrease

Approved items are no longer required

These items should be entered as negative figures - either a negative quantity or a negative cost.

 

Variation – PC/PS
This variation type is used when the original approved item was a PC/PS sum.

PC/PS items are typically estimated costs, such as allowances for materials or fixtures.

 

Once the actual cost is known, the vendor submits a Variation – PC/PS to adjust the approved amount to match the final cost.

 

Creating a Variation
Variations can be created from scratch or from an existing quote.

 

From Scratch
Open the job

Select Create → Quote

Change the Quote Type to either:

Variation

Variation – PC/PS

Select the reason for the variation

 

From an Existing Quote
Open the original quote

Select Create → Duplicate Quote

Change the Quote Type to a variation type

You can then update the line items and pricing as required. 

 

Please note that this does create the quote on the job the original quote exists on - this shouldn’t be done if the variation is for a different job (for example, you should not duplicate a Builder Assessment quote, if the Variation is for the Builder Works job).

 

Submitting the Variation
Once the variation is complete:

Publish the quote

The variation will auto-approve or the Insurer will review the variation

If approved:

The approved items will be added to the existing Purchase Order on the job the variation is submitted on

The Purchase Order value will update

The vendor can then invoice for the updated amount

If the Purchase Order was previously completed, this will re-open it
